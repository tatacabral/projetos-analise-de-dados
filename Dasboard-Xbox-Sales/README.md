# 🎮 Análise de Vendas de Assinaturas — Xbox Game Pass

## 📌 Sobre o Projeto

Este projeto consiste no desenvolvimento de um dashboard interativo em Excel para análise de vendas de assinaturas do Xbox Game Pass, criado durante o **Bootcamp Santander — Excel com IA e Claude**.

O objetivo é explorar dados de assinaturas e transformar informações em indicadores visuais que facilitem a compreensão dos resultados e apoiem a análise de questões de negócio relacionadas às vendas de planos e serviços adicionais.

A análise foi desenvolvida com uma base de dados limitada, utilizada exclusivamente para fins educacionais e demonstrativos.

## 🎯 Objetivos da Análise

- Desenvolver um dashboard para visualização dos indicadores de vendas.
- Organizar e analisar dados relacionados aos planos de assinatura.
- Investigar o faturamento e a quantidade de vendas de planos anuais, trimestrais e mensais.
- Analisar a participação dos serviços adicionais EA Play e Minecraft Season Pass.
- Explorar a distribuição das vendas por tipo de plano e a opção de renovação automática.

## 🔎 Perguntas de Negócio

O dashboard foi desenvolvido para responder às seguintes perguntas:

1. **Qual é o faturamento total das vendas de planos anuais, trimestrais e mensais?**
2. **Como o faturamento dos planos anuais, trimestrais e mensais se distribui entre assinaturas com e sem renovação automática?**
3. **Qual é o valor total das vendas de assinaturas do EA Play?**
4. **Qual é o valor total das vendas do Minecraft Season Pass?**
5. **Como o faturamento se distribui entre os diferentes tipos de plano (Core, Standard e Ultimate)?**
6. **Como se distribui mensalmente a quantidade de assinaturas anuais, trimestrais e mensais vendidas?**
7. **Qual é a quantidade de assinaturas anuais, trimestrais e mensais vendidas no período analisado?**

## 🛠️ Ferramentas e Recursos

- **Microsoft Excel:** organização dos dados, cálculos e construção do dashboard.
- **Tabelas Dinâmicas:** consolidação e análise das informações por categorias.
- **Gráficos:** representação visual dos indicadores para facilitar a interpretação dos dados.
- **Indicadores de negócio (KPIs):** acompanhamento de métricas relacionadas às vendas e ao faturamento.

## 📊 Estrutura do Projeto

O arquivo Excel está organizado em quatro abas principais:

- **Assets:** reúne a paleta de cores e os elementos visuais utilizados na identidade do dashboard.
- **Bases:** contém os dados das assinaturas, incluindo tipo de plano, data de início, renovação automática, preços e serviços adicionais.
- **Cálculos:** concentra as análises e tabelas de apoio utilizadas para responder às perguntas de negócio.
- **Dashboard:** apresenta a visualização gráfica das informações analisadas.

## 💡 Aprendizados

O desenvolvimento deste projeto proporcionou a prática de habilidades importantes para a análise de dados, como:

- Organização e estruturação de bases de dados.
- Consolidação de informações por meio de Tabelas Dinâmicas.
- Construção de indicadores para responder a perguntas de negócio.
- Desenvolvimento de dashboards com foco em visualização e clareza.
- Transformação de dados em informações que facilitam a interpretação dos resultados.

## ⚠️ Observação sobre os Dados

Este projeto possui finalidade exclusivamente educacional. A base utilizada contém uma quantidade limitada de informações para demonstração das funcionalidades do Excel e das técnicas de análise de dados.

Portanto, os resultados apresentados não representam dados oficiais de vendas, faturamento ou desempenho comercial do Xbox Game Pass.
